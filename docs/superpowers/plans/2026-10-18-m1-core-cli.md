# wtfsync Milestone 1 (Core CLI) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `wtfsync.exe` CLI (`init`, `link`, `push`, `pull`, `status`, `restore`) that syncs WoW SavedVariables between PCs through a cloud-synced folder, with three-way conflict handling, backups, an offline retry, and snapshot retention.

**Architecture:** Small leaf packages (`wow`, `collect`, `archive`, `syncdir`, `local`, `fsutil`) each own one concern and are tested alone against temp dirs; `engine` composes them into push/pull/status/restore for one flavor; `cli` parses flags, prompts in the terminal, and loops over flavors. Windows-only code is limited to the process list (behind `wow.Processes`) so everything else is tested on Linux, and CI also runs the suite on `windows-latest`.

**Tech Stack:** Go 1.26, standard library (`archive/tar`, `compress/gzip`, `crypto/sha256`, `encoding/json`, `flag`), `golang.org/x/sys/windows`, GitHub Actions.

**Spec:** [`docs/superpowers/specs/2026-10-18-wtfsync-design.md`](../specs/2026-10-18-wtfsync-design.md)

## Global Constraints

- Module path `github.com/rhwendt/wtfsync`; `go 1.26` in `go.mod`.
- Only third-party dependency: `golang.org/x/sys` (Windows process listing). Everything else is stdlib.
- Name is `wtfsync` everywhere: binary `wtfsync.exe`, cloud folder `<sync folder>/wtfsync/`, local folder `%APPDATA%\wtfsync\` (`os.UserConfigDir()` + `wtfsync`).
- Cloud layout: `wtfsync/wtfsync.json` = `{"format": 1, "encryption": "none", "created": "<utc>"}`; `wtfsync/machines/<uuid>.json`; `wtfsync/<flavor>/snapshots/<seq>_<utc>_<uuid>.tar.gz` with `<seq>` zero-padded to 6 digits and `<utc>` = `YYYYMMDDTHHMMSSZ`.
- Snapshots are immutable: created via temp file + rename, never overwritten. A machine only ever writes its own `machines/<uuid>.json`.
- Newest snapshot = highest `seq`, ties broken by `<utc>`, then UUID.
- Synced files (per flavor, relative to `WTF/`): `Account/*/SavedVariables/*.lua` and `Account/*/*/*/SavedVariables/*.lua`. Excluded: `*.lua.bak`, `Config.wtf`, everything else.
- Retention: newest **20** snapshots per flavor; newest **10** backup sets per flavor. Placeholder hydration timeout **60s**.
- Exit codes: `0` ok, `1` error, `2` refused (game running / not hydrated), `3` unresolved conflict (prompt aborted).
- No encryption in v1.
- Pull, push and restore are refused while that flavor's game process is running.
- Work on branch `feature/m1-core-cli`. Conventional Commits. **No `Claude-Session:` trailer or session URLs in commits/PRs** (user's global rule); `Co-Authored-By` is fine.

**Plan decisions that refine the spec** (flagged for the reviewer):
1. M1 builds a plain console executable. The GUI-subsystem build + `AttachConsole` arrive with the tray in M2 (no tray in M1, so no window to hide).
2. "Game running" = any running `wow*.exe` whose path is inside that flavor's `_<flavor>_` folder. This distinguishes `classic` from `classic_era` (both `WowClassic.exe`) without a per-flavor name table, so process names drop off the M3 verification list (launch codes stay).
3. WoW install detection in M1: `--wow-dir`, else the default install paths, else ask. Battle.net-config detection waits for M3 (its format is on the spec's to-verify list).
4. `--name` flag added to `init`/`link` so setup can run non-interactively (tests).
5. A pending push is retried at the start of `pull` and `status`; `push` itself just pushes.
6. First-link "use the other PC's settings for everything" applies to **conflicting** files. Files only on this PC are kept (and pushed next time) rather than deleted.

## Review Focus

1. **Unsafe paths inside a snapshot** (`../x`, `a\..\b`, `C:`): a hand-edited or corrupt snapshot must be rejected as corrupt and nothing written outside `WTF/` → Task 3 (`Synced` table) and Task 5 (`Read` rejects).
2. **Cloud junk in the snapshots folder** (`… (1).tar.gz` conflict copies, `.tmp` files): ignored when listing, never treated as newest → Task 7.
3. **`classic` and `classic_era` running at once / one at a time:** one must not block the other → Task 2.
4. **Aborting a prompt or closing stdin mid-pull:** no local file changes, base unchanged, exit code 3 → Task 12 and Task 17.
5. **Spaces and non-ASCII in realm/character folders** (`Area 52`, `Thrâll`): collected, archived, and written back intact → Task 3, Task 5, Task 17.

// Package wow knows where World of Warcraft keeps its files and whether the game is running.
package wow

import (
	"fmt"
	"os"
	"path/filepath"
	"strings"
)

// Flavor is one installed game flavor, e.g. retail in <root>/_retail_.
type Flavor struct {
	Name string // "retail", "classic", "classic_era", "ptr", ...
	Dir  string // <root>/_retail_
}

func (f Flavor) WTFDir() string    { return filepath.Join(f.Dir, "WTF") }
func (f Flavor) AddOnsDir() string { return filepath.Join(f.Dir, "Interface", "AddOns") }

// Flavors lists the flavors under an install root: every _<name>_ folder that contains a WTF
// folder, in folder-name order.
func Flavors(root string) ([]Flavor, error) {
	entries, err := os.ReadDir(root)
	if err != nil {
		return nil, fmt.Errorf("read WoW install folder: %w", err)
	}
	var out []Flavor
	for _, e := range entries {
		n := e.Name()
		if !e.IsDir() || len(n) < 3 || !strings.HasPrefix(n, "_") || !strings.HasSuffix(n, "_") {
			continue
		}
		dir := filepath.Join(root, n)
		if fi, err := os.Stat(filepath.Join(dir, "WTF")); err != nil || !fi.IsDir() {
			continue
		}
		out = append(out, Flavor{Name: n[1 : len(n)-1], Dir: dir})
	}
	return out, nil
}

// DefaultInstallDirs are the usual Windows install roots, most likely first.
func DefaultInstallDirs() []string {
	return []string{
		`C:\Program Files (x86)\World of Warcraft`,
		`C:\Program Files\World of Warcraft`,
	}
}
```

package wow

import (
	"fmt"
	"path/filepath"
	"strings"
)

// Processes reports whether a flavor's game client is running.
type Processes interface {
	Running(f Flavor) (bool, error)
}

// ProcessChecker matches running executables against a flavor's folder, so flavors that share an
// executable name (classic and classic_era both run WowClassic.exe) are told apart by path.
type ProcessChecker struct {
	List func() ([]string, error) // full executable paths of running processes
}

func (c ProcessChecker) Running(f Flavor) (bool, error) {
	paths, err := c.List()
	if err != nil {
		return false, fmt.Errorf("list processes: %w", err)
	}
	dir := strings.ToLower(filepath.Clean(f.Dir)) + string(filepath.Separator)
	for _, p := range paths {
		lp := strings.ToLower(filepath.Clean(p))
		base := filepath.Base(lp)
		if strings.HasPrefix(lp, dir) && strings.HasPrefix(base, "wow") && strings.HasSuffix(base, ".exe") {
			return true, nil
		}
	}
	return false, nil
}

// System checks the real process list.
func System() ProcessChecker { return ProcessChecker{List: systemProcesses} }

//go:build windows

package wow

import (
	"errors"
	"unsafe"

	"golang.org/x/sys/windows"
)

// systemProcesses returns the full executable path of every process we're allowed to query.
func systemProcesses() ([]string, error) {
	snap, err := windows.CreateToolhelp32Snapshot(windows.TH32CS_SNAPPROCESS, 0)
	if err != nil {
		return nil, err
	}
	defer windows.CloseHandle(snap)

	var e windows.ProcessEntry32
	e.Size = uint32(unsafe.Sizeof(e))
	var paths []string
	for err = windows.Process32First(snap, &e); err == nil; err = windows.Process32Next(snap, &e) {
		if p, ok := imagePath(e.ProcessID); ok {
			paths = append(paths, p)
		}
	}
	if !errors.Is(err, windows.ERROR_NO_MORE_FILES) {
		return nil, err
	}
	return paths, nil
}

func imagePath(pid uint32) (string, bool) {
	h, err := windows.OpenProcess(windows.PROCESS_QUERY_LIMITED_INFORMATION, false, pid)
	if err != nil {
		return "", false // system/protected processes; never WoW
	}
	defer windows.CloseHandle(h)
	buf := make([]uint16, windows.MAX_LONG_PATH)
	n := uint32(len(buf))
	if err := windows.QueryFullProcessImageName(h, 0, &buf[0], &n); err != nil {
		return "", false
	}
	return windows.UTF16ToString(buf[:n]), true
}
```

import (
	"encoding/json"
	"os"
	"path/filepath"

// WriteAtomic writes data to path through a temp file in the same folder and a rename, creating
// parent folders, so readers (and cloud clients) never see a half-written file.
func WriteAtomic(path string, data []byte) error {
	if err := os.MkdirAll(filepath.Dir(path), 0o755); err != nil {
		return err
	}
	tmp := path + ".tmp"
	if err := os.WriteFile(tmp, data, 0o644); err != nil {
		return err
	}
	if err := os.Rename(tmp, path); err != nil {
		os.Remove(tmp)
		return err
	}
	return nil
}

// WriteJSON writes v as indented JSON with WriteAtomic.
func WriteJSON(path string, v any) error {
	b, err := json.MarshalIndent(v, "", "  ")
	if err != nil {
		return err
	}
	return WriteAtomic(path, append(b, '\n'))
}

// IsDir reports whether path exists and is a folder.
func IsDir(path string) bool {
	fi, err := os.Stat(path)
	return err == nil && fi.IsDir()

import (
	"crypto/sha256"

	"errors"
	"fmt"
	"io/fs"
	"os"
	"path"
	"path/filepath"
	"strings"

// Collect reads every synced SavedVariables file under a flavor's WTF folder, keyed by
// slash-separated path relative to WTF (e.g. "Account/123#1/SavedVariables/ElvUI.lua").
// A missing WTF/Account folder yields an empty map.
func Collect(wtfDir string) (map[string][]byte, error) {
	files := map[string][]byte{}
	acct := filepath.Join(wtfDir, "Account")
	err := filepath.WalkDir(acct, func(p string, d fs.DirEntry, err error) error {
		if err != nil {
			if p == acct && errors.Is(err, fs.ErrNotExist) {
				return fs.SkipAll
			}
			return err
		}
		if d.IsDir() {
			return nil
		}
		rel, err := filepath.Rel(wtfDir, p)
		if err != nil {
			return err
		}
		rel = filepath.ToSlash(rel)
		if !Synced(rel) {
			return nil
		}
		b, err := os.ReadFile(p)
		if err != nil {
			return err
		}
		files[rel] = b
		return nil
	})
	if err != nil {
		return nil, fmt.Errorf("collect %s: %w", wtfDir, err)
	}
	return files, nil
}

// Synced reports whether a WTF-relative slash path is one wtfsync syncs. It also rejects any path
// that could escape the WTF folder, so it doubles as the safety check for paths read from snapshots.
func Synced(rel string) bool {
	parts := strings.Split(rel, "/")
	for _, p := range parts {
		if p == "" || p == "." || p == ".." || strings.ContainsAny(p, `\:`) {
			return false
		}
	}
	if parts[0] != "Account" || !strings.EqualFold(path.Ext(rel), ".lua") {
		return false
	}
	switch len(parts) {
	case 4: // Account/<acct>/SavedVariables/<file>
		return strings.EqualFold(parts[2], "SavedVariables")
	case 6: // Account/<acct>/<realm>/<char>/SavedVariables/<file>
		return strings.EqualFold(parts[4], "SavedVariables")
	}
	return false
}

// Hash returns "sha256:<hex>" for file contents.
func Hash(b []byte) string {
	s := sha256.Sum256(b)
	return "sha256:" + hex.EncodeToString(s[:])
}

// Hashes maps each path to the Hash of its contents.
func Hashes(files map[string][]byte) map[string]string {
	h := make(map[string]string, len(files))
	for p, b := range files {
		h[p] = Hash(b)
	}
	return h
}

package collect

import (
	"bufio"
	"errors"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
	"sort"
	"strings"
)

// Addon is one installed addon as described by its .toc file.
type Addon struct {
	Folder  string `json:"folder"`
	Version string `json:"version,omitempty"`
	Curse   string `json:"curse,omitempty"`
	Wago    string `json:"wago,omitempty"`
	WoWI    string `json:"wowi,omitempty"`
}

// Addons lists the addon folders under Interface/AddOns that have a .toc file, sorted by folder.
// A missing AddOns folder yields nil.
func Addons(addonsDir string) ([]Addon, error) {
	entries, err := os.ReadDir(addonsDir)
	if errors.Is(err, fs.ErrNotExist) {
		return nil, nil
	}
	if err != nil {
		return nil, fmt.Errorf("read addons: %w", err)
	}
	var out []Addon
	for _, e := range entries {
		if !e.IsDir() {
			continue
		}
		toc, err := findTOC(filepath.Join(addonsDir, e.Name()), e.Name())
		if err != nil {
			return nil, err
		}
		if toc == "" {
			continue
		}
		a, err := parseTOC(toc)
		if err != nil {
			return nil, err
		}
		a.Folder = e.Name()
		out = append(out, a)
	}
	return out, nil
}

// findTOC prefers <folder>.toc, else the first <folder>_*.toc (e.g. ElvUI_Mainline.toc).
func findTOC(dir, folder string) (string, error) {
	entries, err := os.ReadDir(dir)
	if err != nil {
		return "", err
	}
	var alt []string
	for _, e := range entries {
		n := e.Name()
		if e.IsDir() || !strings.EqualFold(filepath.Ext(n), ".toc") {
			continue
		}
		stem := strings.TrimSuffix(n, filepath.Ext(n))
		if strings.EqualFold(stem, folder) {
			return filepath.Join(dir, n), nil
		}
		if len(stem) > len(folder) && strings.EqualFold(stem[:len(folder)+1], folder+"_") {
			alt = append(alt, n)
		}
	}
	if len(alt) == 0 {
		return "", nil
	}
	sort.Strings(alt)
	return filepath.Join(dir, alt[0]), nil
}

func parseTOC(p string) (Addon, error) {
	f, err := os.Open(p)
	if err != nil {
		return Addon{}, err
	}
	defer f.Close()
	var a Addon
	sc := bufio.NewScanner(f)
	for sc.Scan() {
		line := strings.TrimSpace(strings.TrimPrefix(sc.Text(), "\ufeff"))
		if !strings.HasPrefix(line, "##") {
			continue
		}
		key, val, ok := strings.Cut(line[2:], ":")
		if !ok {
			continue
		}
		val = strings.TrimSpace(val)
		switch strings.ToLower(strings.TrimSpace(key)) {
		case "version":
			a.Version = val
		case "x-curse-project-id":
			a.Curse = val
		case "x-wago-id":
			a.Wago = val
		case "x-wowi-id":
			a.WoWI = val
		}
	}
	return a, sc.Err()
}

// Missing returns the folders in other that aren't in installed (compared case-insensitively), sorted.
func Missing(installed, other []Addon) []string {
	have := map[string]bool{}
	for _, a := range installed {
		have[strings.ToLower(a.Folder)] = true
	}
	var out []string
	for _, a := range other {
		if !have[strings.ToLower(a.Folder)] {
			out = append(out, a.Folder)
		}
	}
	sort.Strings(out)
	return out
}

// Package archive builds and reads snapshot files: a gzip tar holding manifest.json first, then each
// SavedVariables file at its WTF-relative path.
package archive

import (
	"archive/tar"
	"compress/gzip"
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"maps"
	"slices"
	"time"

	"github.com/rhwendt/wtfsync/internal/collect"
)

// Format is the snapshot format version this build reads and writes.
const Format = 1

const manifestName = "manifest.json"

var ErrCorrupt = errors.New("corrupt snapshot")

type Machine struct {
	UUID string `json:"uuid"`
	Name string `json:"name"`
}

type Manifest struct {
	Format  int               `json:"format"`
	Machine Machine           `json:"machine"`
	Created time.Time         `json:"created"`
	Flavor  string            `json:"flavor"`
	Seq     int               `json:"seq"`
	Base    string            `json:"base"`  // snapshot the writer was synced with; "" for its first push
	Files   map[string]string `json:"files"` // WTF-relative path → collect.Hash
	Addons  []collect.Addon   `json:"addons"`
}

// Write writes a snapshot of files. It sets m.Format and fills m.Files from files.
func Write(w io.Writer, m Manifest, files map[string][]byte) error {
	m.Format = Format
	m.Files = collect.Hashes(files)
	mj, err := json.MarshalIndent(m, "", "  ")
	if err != nil {
		return err
	}
	gz := gzip.NewWriter(w)
	tw := tar.NewWriter(gz)
	if err := writeEntry(tw, manifestName, mj, m.Created); err != nil {
		return err
	}
	for _, p := range slices.Sorted(maps.Keys(files)) {
		if err := writeEntry(tw, p, files[p], m.Created); err != nil {
			return err
		}
	}
	if err := tw.Close(); err != nil {
		return err
	}
	return gz.Close()
}

func writeEntry(tw *tar.Writer, name string, body []byte, mod time.Time) error {
	hdr := &tar.Header{Name: name, Mode: 0o644, Size: int64(len(body)), ModTime: mod, Typeflag: tar.TypeReg}
	if err := tw.WriteHeader(hdr); err != nil {
		return err
	}
	_, err := tw.Write(body)
	return err
}

func corrupt(format string, args ...any) error {
	return fmt.Errorf("%w: %s", ErrCorrupt, fmt.Sprintf(format, args...))
}

// Read parses a snapshot and checks it: manifest first, known format, only safe synced paths, and
// every listed file present with the listed hash. Any problem is reported as ErrCorrupt.
func Read(r io.Reader) (Manifest, map[string][]byte, error) {
	var m Manifest
	gz, err := gzip.NewReader(r)
	if err != nil {
		return m, nil, corrupt("%v", err)
	}
	tr := tar.NewReader(gz)
	hdr, err := tr.Next()
	if err != nil || hdr.Name != manifestName {
		return m, nil, corrupt("manifest.json is not the first entry")
	}
	mj, err := io.ReadAll(tr)
	if err != nil {
		return m, nil, corrupt("%v", err)
	}
	if err := json.Unmarshal(mj, &m); err != nil {
		return m, nil, corrupt("manifest: %v", err)
	}
	if m.Format != Format {
		return m, nil, corrupt("unsupported format %d", m.Format)
	}
	files := map[string][]byte{}
	for {
		hdr, err := tr.Next()
		if err == io.EOF {
			break
		}
		if err != nil {
			return m, nil, corrupt("%v", err)
		}
		if !collect.Synced(hdr.Name) {
			return m, nil, corrupt("unexpected path %q", hdr.Name)
		}
		want, ok := m.Files[hdr.Name]
		if !ok {
			return m, nil, corrupt("%s is not in the manifest", hdr.Name)
		}
		b, err := io.ReadAll(tr)
		if err != nil {
			return m, nil, corrupt("%v", err)
		}
		if collect.Hash(b) != want {
			return m, nil, corrupt("%s does not match its hash", hdr.Name)
		}
		files[hdr.Name] = b
	}
	if _, err := io.Copy(io.Discard, gz); err != nil { // verifies the gzip checksum
		return m, nil, corrupt("%v", err)
	}
	if len(files) != len(m.Files) {
		return m, nil, corrupt("%d file(s) listed in the manifest are missing", len(m.Files)-len(files))
	}
	return m, files, nil
}

package syncdir

import (
	"errors"
	"fmt"
	"os"
	"path/filepath"
	"time"
)

// DefaultHydrateTimeout is how long to wait for a cloud placeholder file to download.
const DefaultHydrateTimeout = 60 * time.Second

var ErrNotHydrated = errors.New("file hasn't downloaded from the cloud yet")

// Hydrator reads a file from the sync folder, making the cloud client download it if it is only a
// placeholder (Google Drive streaming, OneDrive/iCloud files-on-demand).
type Hydrator interface {
	ReadFile(path string) ([]byte, error)
}

// TimeoutHydrator reads the whole file, which makes the cloud client fetch it. If that takes longer
// than Timeout it gives up with ErrNotHydrated. (The abandoned read finishes or fails on its own.)
type TimeoutHydrator struct {
	Timeout time.Duration
}

func (h TimeoutHydrator) ReadFile(path string) ([]byte, error) {
	type result struct {
		b   []byte
		err error
	}
	ch := make(chan result, 1)
	go func() {
		b, err := os.ReadFile(path)
		ch <- result{b, err}
	}()
	select {
	case r := <-ch:
		return r.b, r.err
	case <-time.After(h.Timeout):
		return nil, fmt.Errorf("%w: %s", ErrNotHydrated, filepath.Base(path))
	}
}

	ErrUnreachable        = errors.New("sync folder unreachable")
	ErrNotInitialized     = errors.New("no wtfsync data in this folder")
	ErrAlreadyInitialized = errors.New("this folder already has wtfsync data")

type Dir struct {
	Root     string // <sync folder>/wtfsync
	Hydrator Hydrator
}

type config struct {
	Format     int       `json:"format"`
	Encryption string    `json:"encryption"`
	Created    time.Time `json:"created"`
}

// MachineRecord describes one PC. UUID is its identity; Name is only a label the user can change.
type MachineRecord struct {
	UUID     string    `json:"uuid"`
	Name     string    `json:"name"`
	LastSeen time.Time `json:"lastSeen"`

func reachable(folder string) error {
	fi, err := os.Stat(folder)
	if err != nil {
		return fmt.Errorf("%w: %v", ErrUnreachable, err)
	}
	if !fi.IsDir() {
		return fmt.Errorf("%w: %s is not a folder", ErrUnreachable, folder)
	}
	return nil
}

// Init creates wtfsync's folder inside folder (setup on the first PC).
func Init(folder string, now time.Time, h Hydrator) (*Dir, error) {
	if err := reachable(folder); err != nil {
		return nil, err
	}
	d := &Dir{Root: filepath.Join(folder, dirName), Hydrator: h}
	if _, err := os.Stat(filepath.Join(d.Root, configName)); err == nil {
		return nil, ErrAlreadyInitialized
	}
	cfg := config{Format: format, Encryption: "none", Created: now.UTC()}
	if err := fsutil.WriteJSON(filepath.Join(d.Root, configName), cfg); err != nil {
		return nil, err
	}
	return d, nil
}

// Open opens the wtfsync folder a first PC created inside folder.
func Open(folder string, h Hydrator) (*Dir, error) {
	if err := reachable(folder); err != nil {
		return nil, err
	}
	d := &Dir{Root: filepath.Join(folder, dirName), Hydrator: h}
	var cfg config
	if err := d.readJSON(filepath.Join(d.Root, configName), &cfg); err != nil {
		if errors.Is(err, fs.ErrNotExist) {
			return nil, ErrNotInitialized
		}
		return nil, err
	}
	if cfg.Format != format || cfg.Encryption != "none" {
		return nil, fmt.Errorf("unsupported wtfsync data (format %d, encryption %q): update wtfsync", cfg.Format, cfg.Encryption)
	}
	return d, nil
}

func (d *Dir) readJSON(path string, v any) error {
	b, err := d.Hydrator.ReadFile(path)
	if err != nil {
		return err
	}
	if err := json.Unmarshal(b, v); err != nil {
		return fmt.Errorf("%s: %w", filepath.Base(path), err)
	}
	return nil
}

	return filepath.Join(d.Root, "machines", uuid+".json")
}

// WriteMachine writes this PC's record. Each PC only ever writes its own file.
func (d *Dir) WriteMachine(r MachineRecord) error {
	r.LastSeen = r.LastSeen.UTC()
	return fsutil.WriteJSON(d.machinePath(r.UUID), r)
}

// Machine reads a PC's record.
func (d *Dir) Machine(uuid string) (MachineRecord, error) {
	var r MachineRecord
	err := d.readJSON(d.machinePath(uuid), &r)
	return r, err

package syncdir

import (
	"errors"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
	"regexp"
	"sort"
	"strconv"
	"time"

	"github.com/rhwendt/wtfsync/internal/fsutil"
)

const timeLayout = "20060102T150405Z"

var nameRE = regexp.MustCompile(`^(\d{6,})_(\d{8}T\d{6}Z)_([0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12})\.tar\.gz$`)

// SnapshotName identifies a snapshot: <seq>_<utc>_<machine uuid>.tar.gz.
type SnapshotName struct {
	Seq  int
	Time time.Time
	UUID string
}

func (n SnapshotName) String() string {
	return fmt.Sprintf("%06d_%s_%s.tar.gz", n.Seq, n.Time.UTC().Format(timeLayout), n.UUID)
}

// Before orders snapshots by seq, then time, then UUID, so a PC with a wrong clock can't make an
// old snapshot look newest and two PCs that pushed the same seq still sort the same way everywhere.
func (n SnapshotName) Before(o SnapshotName) bool {
	if n.Seq != o.Seq {
		return n.Seq < o.Seq
	}
	if !n.Time.Equal(o.Time) {
		return n.Time.Before(o.Time)
	}
	return n.UUID < o.UUID
}

// ParseName parses a snapshot file name; anything else (temp files, cloud conflict copies) is rejected.
func ParseName(s string) (SnapshotName, bool) {
	m := nameRE.FindStringSubmatch(s)
	if m == nil {
		return SnapshotName{}, false
	}
	seq, err := strconv.Atoi(m[1])
	if err != nil {
		return SnapshotName{}, false
	}
	t, err := time.Parse(timeLayout, m[2])
	if err != nil {
		return SnapshotName{}, false
	}
	return SnapshotName{Seq: seq, Time: t, UUID: m[3]}, true
}

func (d *Dir) snapshotDir(flavor string) string {
	return filepath.Join(d.Root, flavor, "snapshots")
}

// Snapshots lists a flavor's snapshots, oldest first.
func (d *Dir) Snapshots(flavor string) ([]SnapshotName, error) {
	entries, err := os.ReadDir(d.snapshotDir(flavor))
	if errors.Is(err, fs.ErrNotExist) {
		return nil, nil
	}
	if err != nil {
		return nil, err
	}
	var out []SnapshotName
	for _, e := range entries {
		if n, ok := ParseName(e.Name()); ok && !e.IsDir() {
			out = append(out, n)
		}
	}
	sort.Slice(out, func(i, j int) bool { return out[i].Before(out[j]) })
	return out, nil
}

// Newest returns the newest snapshot of a flavor; ok is false if there are none.
func (d *Dir) Newest(flavor string) (n SnapshotName, ok bool, err error) {
	all, err := d.Snapshots(flavor)
	if err != nil || len(all) == 0 {
		return SnapshotName{}, false, err
	}
	return all[len(all)-1], true, nil
}

// ReadSnapshot reads a snapshot through the Hydrator.
func (d *Dir) ReadSnapshot(flavor string, n SnapshotName) ([]byte, error) {
	return d.Hydrator.ReadFile(filepath.Join(d.snapshotDir(flavor), n.String()))
}

// WriteSnapshot stores a new snapshot. Snapshots are immutable, so an existing name is an error.
func (d *Dir) WriteSnapshot(flavor string, n SnapshotName, data []byte) error {
	p := filepath.Join(d.snapshotDir(flavor), n.String())
	if _, err := os.Stat(p); err == nil {
		return fmt.Errorf("snapshot %s already exists", n)
	}
	return fsutil.WriteAtomic(p, data)
}

// Prune deletes a flavor's oldest snapshots so that keep remain, skipping names in protect.
func (d *Dir) Prune(flavor string, keep int, protect map[string]bool) error {
	all, err := d.Snapshots(flavor)
	if err != nil {
		return err
	}
	for _, n := range all[:max(0, len(all)-keep)] {
		if protect[n.String()] {
			continue
		}
		err := os.Remove(filepath.Join(d.snapshotDir(flavor), n.String()))
		if err != nil && !errors.Is(err, fs.ErrNotExist) {
			return err
		}
	}
	return nil
}

import (

// Candidates returns existing folders that look like a cloud client's synced root, for the setup
// prompt: OneDrive (from its env vars), Dropbox and iCloud under the profile, and Google Drive for

func Candidates(getenv func(string) string, isDir func(string) bool) []string {
	var out []string
	add := func(p string) {
		if p != "" && !slices.Contains(out, p) && isDir(p) {

		}

	add(getenv("OneDriveConsumer"))

		add(filepath.Join(home, "iCloudDrive"))
		add(filepath.Join(home, "My Drive"))
	}
	for l := 'D'; l <= 'Z'; l++ {
		add(string(l) + `:\My Drive`)
	}
	return out

package local

import (
	"errors"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
	"sort"
	"time"

	"github.com/rhwendt/wtfsync/internal/fsutil"
)

const (
	keepBackups  = 10
	backupLayout = "20060102T150405.000Z"
)

type backupIndex struct {
	Present []string `json:"present"` // backed-up files, under files/
	Absent  []string `json:"absent"`  // paths that didn't exist locally at backup time
}

func (s Store) backupDir(flavor, id string) string {
	return filepath.Join(s.Dir, "backups", flavor, id)
}

// Backup saves the current local version of each WTF-relative path into a new backup set, noting
// paths that don't exist, and returns the set id. Only the newest 10 sets per flavor are kept.
func (s Store) Backup(flavor, wtfDir string, paths []string, now time.Time) (string, error) {
	id := now.UTC().Format(backupLayout)
	dir := s.backupDir(flavor, id)
	var idx backupIndex
	for _, p := range paths {
		b, err := os.ReadFile(filepath.Join(wtfDir, filepath.FromSlash(p)))
		if errors.Is(err, fs.ErrNotExist) {
			idx.Absent = append(idx.Absent, p)
			continue
		}
		if err != nil {
			return "", fmt.Errorf("back up %s: %w", p, err)
		}
		if err := fsutil.WriteAtomic(filepath.Join(dir, "files", filepath.FromSlash(p)), b); err != nil {
			return "", err
		}
		idx.Present = append(idx.Present, p)
	}
	if err := fsutil.WriteJSON(filepath.Join(dir, "index.json"), idx); err != nil {
		return "", err
	}
	return id, s.pruneBackups(flavor)
}

// BackupSets lists a flavor's backup set ids, newest first.
func (s Store) BackupSets(flavor string) ([]string, error) {
	entries, err := os.ReadDir(filepath.Join(s.Dir, "backups", flavor))
	if errors.Is(err, fs.ErrNotExist) {
		return nil, nil
	}
	if err != nil {
		return nil, err
	}
	var ids []string
	for _, e := range entries {
		if !e.IsDir() {
			continue
		}
		if _, err := os.Stat(filepath.Join(s.backupDir(flavor, e.Name()), "index.json")); err == nil {
			ids = append(ids, e.Name())
		}
	}
	sort.Sort(sort.Reverse(sort.StringSlice(ids)))
	return ids, nil
}

func (s Store) pruneBackups(flavor string) error {
	ids, err := s.BackupSets(flavor)
	if err != nil {
		return err
	}
	for _, id := range ids[min(len(ids), keepBackups):] {
		if err := os.RemoveAll(s.backupDir(flavor, id)); err != nil {
			return err
		}
	}
	return nil
}

// Restore puts a backup set back into wtfDir: backed-up files are rewritten and files that were
// absent at backup time are deleted.
func (s Store) Restore(flavor, id, wtfDir string) error {
	if id == "" || id == "." || id == ".." || filepath.Base(id) != id {
		return fmt.Errorf("invalid backup id %q", id)
	}
	dir := s.backupDir(flavor, id)
	var idx backupIndex
	if err := readJSON(filepath.Join(dir, "index.json"), &idx); err != nil {
		if errors.Is(err, fs.ErrNotExist) {
			return fmt.Errorf("no backup %q for %s", id, flavor)
		}
		return err
	}
	for _, p := range idx.Present {
		b, err := os.ReadFile(filepath.Join(dir, "files", filepath.FromSlash(p)))
		if err != nil {
			return err
		}
		if err := fsutil.WriteAtomic(filepath.Join(wtfDir, filepath.FromSlash(p)), b); err != nil {
			return err
		}
	}
	for _, p := range idx.Absent {
		err := os.Remove(filepath.Join(wtfDir, filepath.FromSlash(p)))
		if err != nil && !errors.Is(err, fs.ErrNotExist) {
			return err
		}
	}
	return nil
}

// Package engine runs push, pull, status, and restore for one flavor.
package engine

import (
	"maps"
	"slices"
)

// Action is what to do with one file when merging a snapshot.
type Action int

const (
	NoOp       Action = iota
	TakeRemote        // write (or delete) the snapshot's version locally
	KeepLocal         // leave the local version; the next push uploads it
	Conflict          // changed on both sides; the user decides
)

func (a Action) String() string {
	return [...]string{"no-op", "take", "keep", "conflict"}[a]
}

// Decide is the three-way rule for one file. Each argument is a hash; "" means the file is absent,
// so deletions follow the same rule as edits.
func Decide(base, local, remote string) Action {
	switch {
	case local == remote:
		return NoOp
	case local == base:
		return TakeRemote
	case remote == base:
		return KeepLocal
	default:
		return Conflict
	}
}

// Item is one file's decision.
type Item struct {
	Path   string
	Action Action
}

// Plan applies Decide to every path in base, local, or remote, sorted by path. No-ops are dropped.
func Plan(base, local, remote map[string]string) []Item {
	paths := map[string]bool{}
	for _, m := range []map[string]string{base, local, remote} {
		for p := range m {
			paths[p] = true
		}
	}
	var items []Item
	for _, p := range slices.Sorted(maps.Keys(paths)) {
		if a := Decide(base[p], local[p], remote[p]); a != NoOp {
			items = append(items, Item{Path: p, Action: a})
		}
	}
	return items
}

// changed counts paths whose hash differs between a and b (including added or removed paths).
func changed(a, b map[string]string) int {
	n := 0
	for p, h := range a {
		if b[p] != h {
			n++
		}
	}
	for p := range b {
		if _, ok := a[p]; !ok {
			n++
		}
	}
	return n
}

package engine

import (
	"bytes"
	"errors"
	"fmt"
	"io/fs"
	"os"

	"time"

	"github.com/rhwendt/wtfsync/internal/archive"

)

var (
	ErrGameRunning = errors.New("game is running")
	ErrAborted     = errors.New("aborted")
)

// Choice settles one conflicting file.
type Choice int

const (
	ChooseRemote Choice = iota // keep the other PC's version
	ChooseLocal                // keep this PC's version
)

// FirstLinkChoice settles all conflicts the first time a PC syncs a flavor (there's no base yet,
// so every file that differs would otherwise be its own conflict).
type FirstLinkChoice int

const (
	AllRemote FirstLinkChoice = iota
	AllLocal
	PerFile
)

// Prompter asks the user to settle conflicts. Returning ErrAborted stops without changes.
type Prompter interface {
	FirstLink(conflicts int, other string) (FirstLinkChoice, error)
	Conflict(path, other string) (Choice, error)
}

type Engine struct {
	Store    local.Store
	Settings local.Settings
	Procs    wow.Processes
	Hydrator syncdir.Hydrator
	Prompt   Prompter
	Now      func() time.Time
}

type Options struct {
	DryRun bool // report what would happen; change nothing
}

// Report describes what a pull or push did (or, with DryRun, would do).
type Report struct {
	Flavor   string
	UpToDate bool // pull: already had the newest snapshot; push: nothing changed since the base

	// Set when a snapshot was merged in (by pull, or by push when this PC was behind).
	Merged        string
	From          string // display name of the PC that wrote Merged
	Items         []Item // per-file decisions, conflicts already resolved (unresolved in a dry run)
	Backup        string // backup set id for files overwritten or deleted
	MissingAddons []string

	// Push only.
	Snapshot      string // snapshot written
	Pushed        int    // files changed since the base
	Pending       bool   // sync folder unreachable; retried later
	PendingReason string
}

func (e *Engine) checkNotRunning(f wow.Flavor) error {
	running, err := e.Procs.Running(f)
	if err != nil {
		return err
	}
	if running {
		return fmt.Errorf("%w: close WoW (%s) first", ErrGameRunning, f.Name)
	}
	return nil
}

// Pull brings the newest snapshot for f into the local WTF folder.
func (e *Engine) Pull(f wow.Flavor, opt Options) (Report, error) {
	rep := Report{Flavor: f.Name}
	if err := e.checkNotRunning(f); err != nil {
		return rep, err
	}
	d, err := syncdir.Open(e.Settings.SyncFolder, e.Hydrator)
	if err != nil {
		return rep, err
	}
	st, err := e.Store.LoadState(f.Name)
	if err != nil {
		return rep, err
	}
	newest, ok, err := d.Newest(f.Name)
	if err != nil {
		return rep, err
	}
	if !ok || newest.String() == st.Base {
		rep.UpToDate = true
		return rep, nil
	}
	_, err = e.merge(f, d, st, newest, opt, &rep)
	return rep, err
}

// merge applies snapshot n to the local WTF folder with the three-way rule and returns the new
// state (base = n). Nothing is written until every conflict is settled. With DryRun it only fills
// rep and returns st unchanged.
func (e *Engine) merge(f wow.Flavor, d *syncdir.Dir, st local.FlavorState, n syncdir.SnapshotName, opt Options, rep *Report) (local.FlavorState, error) {
	data, err := d.ReadSnapshot(f.Name, n)
	if err != nil {
		return st, err
	}
	m, remote, err := archive.Read(bytes.NewReader(data))
	if err != nil {
		return st, fmt.Errorf("snapshot %s: %w", n, err)
	}
	localFiles, err := collect.Collect(f.WTFDir())
	if err != nil {
		return st, err
	}
	installed, err := collect.Addons(f.AddOnsDir())
	if err != nil {
		return st, err
	}
	rep.Merged, rep.From = n.String(), m.Machine.Name
	rep.MissingAddons = collect.Missing(installed, m.Addons)
	items := Plan(st.Files, collect.Hashes(localFiles), m.Files)
	if opt.DryRun {
		rep.Items = items
		return st, nil
	}
	if items, err = e.resolve(items, st.Base == "", m.Machine.Name); err != nil {
		return st, err
	}
	rep.Items = items

	var take []string
	for _, it := range items {
		if it.Action == TakeRemote {
			take = append(take, it.Path)
		}
	}
	if len(take) > 0 {
		if rep.Backup, err = e.Store.Backup(f.Name, f.WTFDir(), take, e.Now()); err != nil {
			return st, err
		}
		for _, p := range take {
			if err := apply(f.WTFDir(), p, remote); err != nil {
				return st, err
			}
		}
	}
	st.Base, st.Files = n.String(), m.Files
	return st, e.Store.SaveState(f.Name, st)
}

// resolve turns every Conflict into TakeRemote or KeepLocal by asking the Prompter. On a first
// link it asks once for all conflicts, unless the user picks "ask per file".
func (e *Engine) resolve(items []Item, firstLink bool, other string) ([]Item, error) {
	conflicts := 0
	for _, it := range items {
		if it.Action == Conflict {
			conflicts++
		}
	}
	if conflicts == 0 {
		return items, nil
	}
	all := Conflict // Conflict = ask per file
	if firstLink {
		c, err := e.Prompt.FirstLink(conflicts, other)
		if err != nil {
			return nil, err
		}
		switch c {
		case AllRemote:
			all = TakeRemote
		case AllLocal:
			all = KeepLocal
		}
	}
	out := make([]Item, len(items))
	copy(out, items)
	for i := range out {
		if out[i].Action != Conflict {
			continue
		}
		if all != Conflict {
			out[i].Action = all
			continue
		}
		c, err := e.Prompt.Conflict(out[i].Path, other)
		if err != nil {
			return nil, err
		}
		out[i].Action = KeepLocal
		if c == ChooseRemote {
			out[i].Action = TakeRemote
		}
	}
	return out, nil
}

// apply writes the snapshot's version of path, or deletes the local file if the snapshot has none.
func apply(wtfDir, path string, remote map[string][]byte) error {
	dst := filepath.Join(wtfDir, filepath.FromSlash(path))
	if b, ok := remote[path]; ok {
		return fsutil.WriteAtomic(dst, b)
	}
	if err := os.Remove(dst); err != nil && !errors.Is(err, fs.ErrNotExist) {
		return err
	}
	return nil
}

package engine

import (
	"bytes"
	"errors"
	"time"

	"github.com/rhwendt/wtfsync/internal/archive"
	"github.com/rhwendt/wtfsync/internal/collect"
	"github.com/rhwendt/wtfsync/internal/local"
	"github.com/rhwendt/wtfsync/internal/syncdir"
	"github.com/rhwendt/wtfsync/internal/wow"
)

const keepSnapshots = 20

// Push uploads this PC's SavedVariables for f as a new snapshot. If another PC pushed since this
// one last synced, that snapshot is merged first so its changes aren't hidden. If the sync folder
// can't be reached the push is marked pending (Report.Pending) rather than failing: the data is the
// local files, which stay put, so the retry just pushes again.
func (e *Engine) Push(f wow.Flavor, opt Options) (Report, error) {
	rep := Report{Flavor: f.Name}
	if err := e.checkNotRunning(f); err != nil {
		return rep, err
	}
	st, err := e.Store.LoadState(f.Name)
	if err != nil {
		return rep, err
	}
	d, err := syncdir.Open(e.Settings.SyncFolder, e.Hydrator)
	if errors.Is(err, syncdir.ErrUnreachable) {
		return e.pending(f, st, opt, rep, err)
	}
	if err != nil {
		return rep, err
	}
	newest, ok, err := d.Newest(f.Name)
	if err != nil {
		return rep, err
	}
	if ok && newest.String() != st.Base {
		if st, err = e.merge(f, d, st, newest, opt, &rep); err != nil {
			return rep, err
		}
	}

	files, err := collect.Collect(f.WTFDir())
	if err != nil {
		return rep, err
	}
	hashes := collect.Hashes(files)
	rep.Pushed = changed(st.Files, hashes)
	if rep.Pushed == 0 {
		rep.UpToDate = true
		if st.PendingPush && !opt.DryRun {
			st.PendingPush = false
			return rep, e.Store.SaveState(f.Name, st)
		}
		return rep, nil
	}
	if opt.DryRun {
		return rep, nil
	}

	addons, err := collect.Addons(f.AddOnsDir())
	if err != nil {
		return rep, err
	}
	name := syncdir.SnapshotName{Seq: 1, Time: e.Now().UTC().Truncate(time.Second), UUID: e.Settings.MachineUUID}
	if ok {
		name.Seq = newest.Seq + 1
	}
	m := archive.Manifest{
		Machine: archive.Machine{UUID: e.Settings.MachineUUID, Name: e.Settings.MachineName},
		Created: name.Time,
		Flavor:  f.Name,
		Seq:     name.Seq,
		Base:    st.Base,
		Addons:  addons,
	}
	var buf bytes.Buffer
	if err := archive.Write(&buf, m, files); err != nil {
		return rep, err
	}
	if err := d.WriteSnapshot(f.Name, name, buf.Bytes()); err != nil {
		return e.pending(f, st, opt, rep, err)
	}
	if err := e.Store.SaveState(f.Name, local.FlavorState{Base: name.String(), Files: hashes}); err != nil {
		return rep, err
	}
	rep.Snapshot = name.String()
	record := syncdir.MachineRecord{UUID: e.Settings.MachineUUID, Name: e.Settings.MachineName, LastSeen: name.Time}
	if err := d.WriteMachine(record); err != nil {
		return rep, err
	}
	return rep, d.Prune(f.Name, keepSnapshots, nil)
}

func (e *Engine) pending(f wow.Flavor, st local.FlavorState, opt Options, rep Report, cause error) (Report, error) {
	rep.Pending, rep.PendingReason = true, cause.Error()
	if opt.DryRun {
		return rep, nil
	}
	st.PendingPush = true
	return rep, e.Store.SaveState(f.Name, st)
}

package engine

import (
	"errors"
	"fmt"

	"github.com/rhwendt/wtfsync/internal/collect"
	"github.com/rhwendt/wtfsync/internal/syncdir"
	"github.com/rhwendt/wtfsync/internal/wow"
)

// Status is a flavor's sync state as `wtfsync status` shows it.
type Status struct {
	Flavor       string
	Base         string // snapshot last synced; "" = never
	Newest       string // newest snapshot in the sync folder; "" = none (or unreachable)
	NewestBy     string // display name of the PC that wrote Newest
	Reachable    bool
	LocalChanges int // files changed here since Base
	PendingPush  bool
}

func (e *Engine) Status(f wow.Flavor) (Status, error) {
	st, err := e.Store.LoadState(f.Name)
	if err != nil {
		return Status{}, err
	}
	files, err := collect.Collect(f.WTFDir())
	if err != nil {
		return Status{}, err
	}
	s := Status{Flavor: f.Name, Base: st.Base, PendingPush: st.PendingPush, LocalChanges: changed(st.Files, collect.Hashes(files))}
	d, err := syncdir.Open(e.Settings.SyncFolder, e.Hydrator)
	if errors.Is(err, syncdir.ErrUnreachable) {
		return s, nil
	}
	if err != nil {
		return s, err
	}
	s.Reachable = true
	n, ok, err := d.Newest(f.Name)
	if err != nil || !ok {
		return s, err
	}
	s.Newest, s.NewestBy = n.String(), n.UUID
	if m, err := d.Machine(n.UUID); err == nil {
		s.NewestBy = m.Name
	}
	return s, nil
}

// Restore puts back a backup set (the newest when id is "") and returns the id restored.
func (e *Engine) Restore(f wow.Flavor, id string) (string, error) {
	if err := e.checkNotRunning(f); err != nil {
		return "", err
	}
	if id == "" {
		sets, err := e.Store.BackupSets(f.Name)
		if err != nil {
			return "", err
		}
		if len(sets) == 0 {
			return "", fmt.Errorf("no backups for %s yet", f.Name)
		}
		id = sets[0]
	}
	return id, e.Store.Restore(f.Name, id, f.WTFDir())
}

  init      set up the first PC: pick the sync folder, then push
  link      set up another PC on the same sync folder, then pull
  push      upload this PC's addon settings
  pull      download the newest addon settings from your other PCs
  status    show sync state for each flavor
  restore   undo the last pull from its backup (--set <id> for an older one)

flags:
  --flavor <name>     only this flavor (default: all enabled)
  --dry-run           show what would change; change nothing
  --wow-dir <path>    WoW install folder (overrides settings)
  --sync-dir <path>   cloud-synced folder (overrides settings)
  --data-dir <path>   wtfsync's local data folder (default %APPDATA%\wtfsync)
  --name <name>       this PC's display name (init, link)
  --set <id>          backup set to restore (restore)
`

type cmd struct {
	deps Deps
	in   *bufio.Reader
	out  io.Writer
	errw io.Writer
}

// Run runs wtfsync with args (without the program name) and returns the process exit code.
func Run(args []string, stdin io.Reader, stdout, stderr io.Writer, deps Deps) int {
	if len(args) == 0 {
		fmt.Fprint(stderr, usage)
		return exitErr
	}
	c := &cmd{deps: deps, in: bufio.NewReader(stdin), out: stdout, errw: stderr}
	var err error
	switch args[0] {
	case "init":
		err = c.setup(args[1:], true)
	case "link":
		err = c.setup(args[1:], false)
	case "push", "pull", "status", "restore":
		err = c.sync(args[0], args[1:])
	case "help", "-h", "--help":
		fmt.Fprint(stdout, usage)
		return exitOK
	default:
		err = fmt.Errorf("unknown command %q (see `wtfsync help`)", args[0])
	}
	if err != nil && !errors.Is(err, flag.ErrHelp) {
		fmt.Fprintln(stderr, "wtfsync:", err)
	}
	return exitCode(err)
}

func exitCode(err error) int {
	switch {
	case err == nil, errors.Is(err, flag.ErrHelp):
		return exitOK
	case errors.Is(err, engine.ErrAborted):
		return exitAborted
	case errors.Is(err, engine.ErrGameRunning), errors.Is(err, syncdir.ErrNotHydrated):
		return exitRefused
	default:
		return exitErr
	}
}

type flags struct {
	flavor, wowDir, syncDir, dataDir, name, set string
	dryRun                                      bool
}

func (c *cmd) parse(name string, args []string) (flags, error) {
	var f flags
	set := flag.NewFlagSet(name, flag.ContinueOnError)
	set.SetOutput(c.errw)
	set.Usage = func() { fmt.Fprint(c.errw, usage) }
	set.StringVar(&f.flavor, "flavor", "", "")
	set.BoolVar(&f.dryRun, "dry-run", false, "")
	set.StringVar(&f.wowDir, "wow-dir", "", "")
	set.StringVar(&f.syncDir, "sync-dir", "", "")
	set.StringVar(&f.dataDir, "data-dir", c.deps.DefaultDataDir, "")
	set.StringVar(&f.name, "name", "", "")
	set.StringVar(&f.set, "set", "", "")
	if err := set.Parse(args); err != nil {
		return f, err
	}
	if set.NArg() > 0 {
		return f, fmt.Errorf("unexpected argument %q", set.Arg(0))
	}
	return f, nil
}

func (c *cmd) prompter() prompter { return prompter{in: c.in, out: c.out} }

func (c *cmd) engine(store local.Store, s local.Settings) *engine.Engine {
	return &engine.Engine{
		Store:    store,
		Settings: s,
		Procs:    c.deps.Procs,
		Hydrator: c.deps.Hydrator,
		Prompt:   c.prompter(),
		Now:      c.deps.Now,
	}
}

// prompter asks questions on the terminal. End of input counts as aborting.
type prompter struct {
	in  *bufio.Reader
	out io.Writer
}

func (p prompter) ask(q string) (string, error) {
	fmt.Fprint(p.out, q)
	line, err := p.in.ReadString('\n')
	if err != nil && line == "" {
		fmt.Fprintln(p.out)
		return "", engine.ErrAborted
	}
	return strings.TrimSpace(line), nil
}

// line asks for a value, using def when the answer is empty.
func (p prompter) line(q, def string) (string, error) {
	if def != "" {
		q = fmt.Sprintf("%s [%s]: ", q, def)
	} else {
		q += ": "
	}
	a, err := p.ask(q)
	if err != nil {
		return "", err
	}
	if a == "" {
		a = def
	}
	if a == "" {
		return "", errors.New("no answer given")
	}
	return a, nil
}

func (p prompter) FirstLink(n int, other string) (engine.FirstLinkChoice, error) {
	q := fmt.Sprintf("This PC and %s both have settings for %d file(s).\n"+
		"  1) use %s's settings for all of them (recommended)\n"+
		"  2) keep this PC's\n"+
		"  3) ask for each file\n"+
		"  a) abort\n"+
		"Choice [1]: ", other, n, other)
	for {
		a, err := p.ask(q)
		if err != nil {
			return 0, err
		}
		switch strings.ToLower(a) {
		case "", "1":
			return engine.AllRemote, nil
		case "2":
			return engine.AllLocal, nil
		case "3":
			return engine.PerFile, nil
		case "a":
			return 0, engine.ErrAborted
		}
		fmt.Fprintln(p.out, "Please answer 1, 2, 3 or a.")
	}
}

func (p prompter) Conflict(path, other string) (engine.Choice, error) {
	q := fmt.Sprintf("%s changed on %s and on this PC.\n"+
		"  r) keep %s's version\n"+
		"  l) keep this PC's version\n"+
		"  a) abort\n"+
		"Choice: ", path, other, other)
	for {
		a, err := p.ask(q)
		if err != nil {
			return 0, err
		}
		switch strings.ToLower(a) {
		case "r":
			return engine.ChooseRemote, nil
		case "l":
			return engine.ChooseLocal, nil
		case "a":
			return 0, engine.ErrAborted
		}
		fmt.Fprintln(p.out, "Please answer r, l or a.")
	}
}

package cli

import (
	"fmt"
	"io"
	"strings"

	"github.com/rhwendt/wtfsync/internal/engine"
)

// printReport prints a pull or push result. op is "pull" or "push".
func printReport(w io.Writer, op string, r engine.Report, dry bool) {
	if r.Merged != "" {
		verb := "pulled"
		switch {
		case op == "push" && dry:
			verb = "would merge"
		case op == "push":
			verb = "merged"
		case dry:
			verb = "would pull"
		}
		fmt.Fprintf(w, "%s: %s %s from %s\n", r.Flavor, verb, r.Merged, r.From)
		for _, it := range r.Items {
			fmt.Fprintf(w, "  %-8s %s\n", it.Action, it.Path)
		}
		if r.Backup != "" {
			fmt.Fprintf(w, "  backup %s (undo with: wtfsync restore --flavor %s)\n", r.Backup, r.Flavor)
		}
		if len(r.MissingAddons) > 0 {
			fmt.Fprintf(w, "  %s has addons not installed here: %s\n", r.From, strings.Join(r.MissingAddons, ", "))
		}
	}
	switch {
	case op == "pull":
		if r.UpToDate {
			fmt.Fprintf(w, "%s: up to date\n", r.Flavor)
		}
	case r.Pending:
		fmt.Fprintf(w, "%s: sync folder unreachable (%s); push will be retried\n", r.Flavor, r.PendingReason)
	case r.UpToDate:
		fmt.Fprintf(w, "%s: nothing to push\n", r.Flavor)
	case dry:
		fmt.Fprintf(w, "%s: would push %d changed file(s)\n", r.Flavor, r.Pushed)
	default:
		fmt.Fprintf(w, "%s: pushed %s (%d file(s) changed)\n", r.Flavor, r.Snapshot, r.Pushed)
	}
}

func printStatus(w io.Writer, s engine.Status) {
	base := s.Base
	if base == "" {
		base = "never synced"
	}
	fmt.Fprintf(w, "%s: base %s; %d local change(s)", s.Flavor, base, s.LocalChanges)
	switch {
	case !s.Reachable:
		fmt.Fprint(w, "; sync folder unreachable")
	case s.Newest == "":
		fmt.Fprint(w, "; no snapshots yet")
	case s.Newest == s.Base:
		fmt.Fprint(w, "; up to date with the sync folder")
	default:
		fmt.Fprintf(w, "; newer snapshot %s from %s", s.Newest, s.NewestBy)
	}
	if s.PendingPush {
		fmt.Fprint(w, "; push pending")
	}
	fmt.Fprintln(w)
}

	"errors"

	"github.com/rhwendt/wtfsync/internal/collect"

)

// setup runs `init` (first PC: create the sync data, then push) or `link` (another PC: join
// existing sync data, then pull).
func (c *cmd) setup(args []string, isInit bool) error {
	op := map[bool]string{true: "init", false: "link"}[isInit]
	fl, err := c.parse(op, args)
	if err != nil {
		return err
	}
	store := local.Store{Dir: fl.dataDir}
	if _, err := store.LoadSettings(); err == nil {
		return fmt.Errorf("this PC is already set up (%s)", filepath.Join(fl.dataDir, "settings.json"))
	} else if !errors.Is(err, local.ErrNoSettings) {
		return err
	}

	p := c.prompter()
	wowDir, err := c.chooseWoWDir(p, fl.wowDir)
	if err != nil {
		return err
	}
	flavors, err := wow.Flavors(wowDir)
	if err != nil {
		return err
	}
	if len(flavors) == 0 {
		return fmt.Errorf("no WoW flavors (folders like _retail_ with a WTF folder) in %s", wowDir)
	}
	if err := c.describe(wowDir, flavors, fl.dryRun); err != nil {
		return err
	}
	folder, err := c.chooseSyncFolder(p, fl.syncDir)
	if err != nil {
		return err
	}
	if fl.dryRun {
		state := "no wtfsync data yet"
		if _, err := syncdir.Open(folder, c.deps.Hydrator); err == nil {
			state = "has wtfsync data"
		}
		fmt.Fprintf(c.out, "Sync folder: %s (%s)\nDry run: nothing written.\n", folder, state)
		return nil
	}

	name := fl.name
	if name == "" {
		host, _ := c.deps.Hostname()
		if name, err = p.line("Name for this PC", host); err != nil {
			return err
		}
	}

	var d *syncdir.Dir
	if isInit {
		d, err = syncdir.Init(folder, c.deps.Now(), c.deps.Hydrator)
		if errors.Is(err, syncdir.ErrAlreadyInitialized) {
			return fmt.Errorf("%w: run `wtfsync link` on this PC instead", err)
		}
	} else {
		d, err = syncdir.Open(folder, c.deps.Hydrator)
		if errors.Is(err, syncdir.ErrNotInitialized) {
			return fmt.Errorf("%w: run `wtfsync init` on your first PC", err)
		}
	}
	if err != nil {
		return err
	}

	s := local.Settings{MachineUUID: local.NewUUID(), MachineName: name, SyncFolder: folder, WoWDir: wowDir, Flavors: map[string]bool{}}
	for _, f := range flavors {
		s.Flavors[f.Name] = true
	}
	if err := d.WriteMachine(syncdir.MachineRecord{UUID: s.MachineUUID, Name: name, LastSeen: c.deps.Now()}); err != nil {
		return err
	}
	if err := store.SaveSettings(s); err != nil {
		return err
	}
	fmt.Fprintf(c.out, "This PC is %q.\n", name)

	eng := c.engine(store, s)
	var errs []error
	for _, f := range flavors {
		var rep engine.Report
		if isInit {
			rep, err = eng.Push(f, engine.Options{})
		} else {
			rep, err = eng.Pull(f, engine.Options{})
		}
		if err != nil {
			errs = append(errs, fmt.Errorf("%s: %w", f.Name, err))
			if errors.Is(err, engine.ErrAborted) {
				break
			}
			continue
		}
		printReport(c.out, map[bool]string{true: "push", false: "pull"}[isInit], rep, false)
	}
	return errors.Join(errs...)
}

// describe prints the install and how many files each flavor has (and lists them when asked).
func (c *cmd) describe(wowDir string, flavors []wow.Flavor, listFiles bool) error {
	fmt.Fprintf(c.out, "WoW install: %s\n", wowDir)
	for _, f := range flavors {
		files, err := collect.Collect(f.WTFDir())
		if err != nil {
			return err
		}
		fmt.Fprintf(c.out, "  %s: %d SavedVariables file(s)\n", f.Name, len(files))
		if listFiles {
			for _, p := range slices.Sorted(maps.Keys(files)) {
				fmt.Fprintf(c.out, "    %s\n", p)
			}
		}
	}
	return nil
}

func (c *cmd) chooseWoWDir(p prompter, flagVal string) (string, error) {
	if flagVal != "" {
		return flagVal, nil
	}
	def := ""
	for _, d := range c.deps.InstallDirs {
		if fsutil.IsDir(d) {
			def = d
			break
		}
	}
	return p.line("WoW install folder", def)
}

func (c *cmd) chooseSyncFolder(p prompter, flagVal string) (string, error) {
	if flagVal != "" {
		return flagVal, nil
	}
	cands := syncdir.Candidates(c.deps.Getenv, fsutil.IsDir)
	if len(cands) == 0 {
		return p.line(`Folder your cloud client syncs (e.g. G:\My Drive)`, "")
	}
	fmt.Fprintln(c.out, "Cloud folders found:")
	for i, f := range cands {
		fmt.Fprintf(c.out, "  %d) %s\n", i+1, f)
	}
	a, err := p.line("Pick a number or type a folder", "1")
	if err != nil {
		return "", err
	}
	if i, err := strconv.Atoi(a); err == nil {
		if i < 1 || i > len(cands) {
			return "", fmt.Errorf("no folder numbered %d", i)
		}
		return cands[i-1], nil
	}
	return a, nil
}

package cli

import (
	"errors"
	"fmt"
	"slices"
	"strings"

	"github.com/rhwendt/wtfsync/internal/engine"
	"github.com/rhwendt/wtfsync/internal/local"
	"github.com/rhwendt/wtfsync/internal/wow"
)

// sync runs push, pull, status, or restore for each selected flavor.
func (c *cmd) sync(op string, args []string) error {
	fl, err := c.parse(op, args)
	if err != nil {
		return err
	}
	store := local.Store{Dir: fl.dataDir}
	s, err := store.LoadSettings()
	if err != nil {
		return err
	}
	if fl.wowDir != "" {
		s.WoWDir = fl.wowDir
	}
	if fl.syncDir != "" {
		s.SyncFolder = fl.syncDir
	}
	flavors, err := selectFlavors(s, fl.flavor)
	if err != nil {
		return err
	}
	eng := c.engine(store, s)
	if (op == "pull" || op == "status") && !fl.dryRun {
		c.retryPending(eng, flavors)
	}
	opt := engine.Options{DryRun: fl.dryRun}
	var errs []error
	for _, f := range flavors {
		if err := c.one(eng, op, f, fl, opt); err != nil {
			errs = append(errs, fmt.Errorf("%s: %w", f.Name, err))
			if errors.Is(err, engine.ErrAborted) {
				break
			}
		}
	}
	return errors.Join(errs...)
}

func (c *cmd) one(eng *engine.Engine, op string, f wow.Flavor, fl flags, opt engine.Options) error {
	switch op {
	case "push", "pull":
		run := eng.Push
		if op == "pull" {
			run = eng.Pull
		}
		r, err := run(f, opt)
		if err != nil {
			return err
		}
		printReport(c.out, op, r, opt.DryRun)
	case "status":
		st, err := eng.Status(f)
		if err != nil {
			return err
		}
		printStatus(c.out, st)
	case "restore":
		id, err := eng.Restore(f, fl.set)
		if err != nil {
			return err
		}
		fmt.Fprintf(c.out, "%s: restored backup %s\n", f.Name, id)
		sets, err := eng.Store.BackupSets(f.Name)
		if err != nil {
			return err
		}
		if others := slices.DeleteFunc(sets, func(s string) bool { return s == id }); len(others) > 0 {
			fmt.Fprintf(c.out, "  older backups (use --set): %s\n", strings.Join(others, ", "))
		}
	}
	return nil
}

// retryPending re-runs pushes that couldn't reach the sync folder last time.
func (c *cmd) retryPending(eng *engine.Engine, flavors []wow.Flavor) {
	for _, f := range flavors {
		st, err := eng.Store.LoadState(f.Name)
		if err != nil || !st.PendingPush {
			continue
		}
		fmt.Fprintf(c.out, "%s: retrying pending push\n", f.Name)
		r, err := eng.Push(f, engine.Options{})
		if err != nil {
			fmt.Fprintf(c.errw, "%s: %v\n", f.Name, err)
			continue
		}
		printReport(c.out, "push", r, false)
	}
}

// selectFlavors returns the installed flavors to act on: just name if given, else every enabled
// flavor. Flavors installed after setup aren't in settings yet and count as enabled.
func selectFlavors(s local.Settings, name string) ([]wow.Flavor, error) {
	all, err := wow.Flavors(s.WoWDir)
	if err != nil {
		return nil, err
	}
	var out []wow.Flavor
	var names []string
	for _, f := range all {
		names = append(names, f.Name)
		if name != "" {
			if f.Name == name {
				return []wow.Flavor{f}, nil
			}
			continue
		}
		if enabled, known := s.Flavors[f.Name]; !known || enabled {
			out = append(out, f)
		}
	}
	if name != "" {
		return nil, fmt.Errorf("unknown flavor %q (installed: %s)", name, strings.Join(names, ", "))
	}
	if len(out) == 0 {
		return nil, fmt.Errorf("no enabled flavors in %s", s.WoWDir)
	}
	return out, nil
}

# wtfsync

Sync World of Warcraft addon settings (SavedVariables) between PCs through a folder your cloud
client already syncs (Google Drive for Desktop, OneDrive, iCloud, Dropbox).

It syncs `WTF/Account/**/SavedVariables/*.lua` for every installed flavor (retail, classic, …).
It never touches `Config.wtf` (graphics/hardware settings stay per-PC) or addon code.

## Setup

On your first PC:

    wtfsync init

On each other PC (point it at the same cloud folder):

    wtfsync link

## Use

Close WoW, then:

    wtfsync push      # after playing
    wtfsync pull      # before playing on the other PC
    wtfsync status    # what's changed, and whether you're behind

If the same addon's settings changed on both PCs, wtfsync asks which one to keep. Every pull backs
up the files it overwrites; `wtfsync restore` puts the last backup back.

Add `--dry-run` to any command to see what it would do without changing anything.

## Build

    GOOS=windows GOARCH=amd64 go build -o wtfsync.exe ./cmd/wtfsync

CI builds `wtfsync.exe` for every PR (artifact `wtfsync-windows-amd64`).

2. `push` / `pull` with `--wow-dir` pointed at a *copy* of the install.
3. NJ ↔ NY through Google Drive for Desktop (including streaming/placeholder mode).
4. Change the same addon on both PCs without syncing: the second push asks.
